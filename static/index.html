Draco Insomnis for static sites

Choose where your HTML lives and what to switch on; download the file and upload it next to your site. Everything happens in this page: nothing is sent anywhere, and nothing of Draco stays on your server that anyone could open.

What it protects, honestly

A static site has no database and no code on the server, so blocking SQL injection or XSS in the address protects nothing there. What matters is: files that should never be public (.git, .env, backups uploaded by mistake), scanners looking for them, security headers and a Content-Security-Policy for your visitors, and — only with a Cloudflare Worker in front — limiting how fast anyone can copy the whole site.
